# DevOps Module 4 - Activity 2

This project was created for Module 4 of Developing in a DevOps Environment at RRC Polytech.

It is a JavaScript application built using Node.js and Express. The application asks the user to enter their name and displays a greeting along with the Docker container's IP address.

The application is deployed using Docker inside an Ubuntu virtual machine configured with Vagrant.

## Technologies Used

- JavaScript
- Node.js
- Express
- Docker
- Ubuntu
- Vagrant
